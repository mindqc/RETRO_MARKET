## Chương 1. Quy Tắc Ánh Xạ Kiểu Dữ Liệu PostgreSQL 18 Sang Laravel Migration Blueprint (`Type Mapping Rules`)

Mọi file Migration trong `backend/database/migrations/` bắt buộc tuân thủ bảng ánh xạ 1:1 dưới đây để sinh ra cấu trúc cột PostgreSQL 18 khớp tuyệt đối với SQL DDL Phase 04:

| Kiểu Dữ Liệu SQL DDL (Phase 04) | Cú Pháp Laravel Schema Blueprint Chuẩn (`P5-02`) | Ghi Chú Kỹ Thuật Bắt Buộc |
| :--- | :--- | :--- |
| `BIGSERIAL PRIMARY KEY` | `$table->id();` | Sinh cột `id bigint primary key generated by default as identity`. |
| `BIGINT NOT NULL REFERENCES x(id)` | `$table->foreignId('...')->constrained('...')->restrictOnDelete();` (hoặc `cascadeOnDelete()` / `nullOnDelete()`) | Khớp 100% ma trận `ON DELETE` trong `ERD_RELATIONSHIPS.md`. |
| `NUMERIC(15, 2) NOT NULL` | `$table->decimal('...', 15, 2);` | Áp dụng cho mọi cột tiền tệ (`BR-FN-01`). Tuyệt đối không dùng `float()` hay `double()`. |
| `NUMERIC(5, 2)` / `NUMERIC(3, 2)` / `NUMERIC(5, 4)` | `$table->decimal('trust_score', 5, 2)` / `$table->decimal('average_rating', 3, 2)` / `$table->decimal('protection_fee_rate_applied', 5, 4)` | Đảm bảo độ chính xác cho điểm uy tín, điểm sao và tỷ lệ % phí bảo vệ. |
| `TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP` | `$table->timestampTz('created_at')->useCurrent();` hoặc `$table->timestampsTz();` | **Bắt buộc có hậu tố `Tz`** (`TECH-03`, `BR-AU-01`) để tạo kiểu `TIMESTAMPTZ` trên PostgreSQL 18. |
| `TIMESTAMPTZ NULL` | `$table->timestampTz('...')->nullable();` | Dùng cho các mốc thời gian trạng thái (`paid_at`, `delivered_at`, `auto_complete_at`, `escrow_frozen_at`...). |
| `JSONB` | `$table->jsonb('...');` | Dùng cho `orders.shipping_address_snapshot`, `audit_logs.old_values`, `audit_logs.new_values`. |
| `SMALLINT` / `INTEGER` | `$table->smallInteger('...')` / `$table->integer('...')` | Dùng cho `sort_order`, `rating (1..5)`, `quantity`, `bid_count`, `extended_count`. |

## Chương 4. Kết Quả Kiểm Thử Thực Tế (`Audit Log`)

### 4.1. Thực Thi Lệnh Migrate, Rollback & Re-migrate
1. `php artisan migrate:fresh`: Thành công 100% cả 5 Tier migration.
2. `php artisan migrate:rollback --step=5`: Thành công 100% drop bảng từ Tier 5 về Tier 1 không gặp lỗi khóa ngoại.
3. `php artisan migrate`: Thành công 100% tái tạo 34 bảng nghiệp vụ.

### 4.2. Thống Kê Cơ Sở Dữ Liệu PostgreSQL 18
- **Tổng số bảng:** 35 bảng (34 bảng nghiệp vụ + 1 bảng `migrations`).
- **Partial Unique Indexes:** 2 (`uq_auctions_active_product`, `uq_payments_one_paid_per_order`).
- **Cột JSONB:** 3 (`audit_logs.old_values`, `audit_logs.new_values`, `orders.shipping_address_snapshot`).
- **Cột Timestamps:** 100% là `timestamptz` (`timestamp with time zone`), 0 cột `timestamp without time zone`.
- **Cột Numeric:** 32 cột tuân thủ độ chính xác tiền tệ (`15, 2`) và tỷ lệ (`5, 4`, `5, 2`, `3, 2`).
- **Platform Settings:** Đã nạp đủ 12 dòng cấu hình mặc định (phí bảo vệ, thời gian hạn chót, timer Demo Mode).
