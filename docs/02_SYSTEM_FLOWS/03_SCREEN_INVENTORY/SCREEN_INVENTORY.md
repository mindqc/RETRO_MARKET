## Chương 1. Tổng Quan Danh Mục Màn Hình & Chuẩn Trạng Thái Giao Diện (`UI State Standards`)

Tài liệu này tổng hợp và đặc tả chi tiết toàn bộ **70 màn hình, hộp thoại và modal** của hệ thống **RETRO MARKET (`izithrift`)**, bao gồm:
- **49 Màn hình & Modal trên Ứng dụng Di động Flutter (`M-*`):** Phủ kín 22 phân hệ chức năng và toàn bộ các luồng `BF-01..12`, `SF-01..12`, `AF-01..09`, `OF-01..10`.
- **21 Màn hình Quản trị trên Laravel Blade Admin Dashboard (`A-*`):** Phủ kín 14 phân hệ quản trị + **Developer Tools (Demo Mode)** theo luồng `AFW-01..10`.

### 1.1. Quy Tắc Bắt Buộc Về 4 Trạng Thái Giao Diện (`NFR-UX-03`)
Mọi màn hình có tải dữ liệu từ Backend API bắt buộc phải cài đặt đầy đủ 4 trạng thái hiển thị sau:
1. **`LOADING`:** Hiển thị `Shimmer / Skeleton Card` trên nền kem ấm (`Warm Cream #F4EBDD`) hoặc vòng xoay chờ trên nút bấm (`Button Spinner`) khi đang gửi Form.
2. **`EMPTY`:** Hiển thị minh họa phong cách Vintage + câu thông báo tiếng Việt rõ nghĩa + nút kêu gọi hành động (`CTA Button`, ví dụ: *"Giỏ hàng đang trống – Khám phá đồ si ngay"*).
3. **`ERROR`:** Hiển thị thông báo lỗi tiếng Việt thân thiện (từ mã `401`, `403`, `404`, `409`, `422`, `429`, `500`) kèm nút **`[Thử lại]`**.
4. **`SUCCESS`:** Hiển thị dữ liệu chuẩn xác với phân tầng Typography 3 lớp (`Wichita Vintage` $\rightarrow$ `Fraunces` $\rightarrow$ `Be Vietnam Pro` – `ADR-07`).
